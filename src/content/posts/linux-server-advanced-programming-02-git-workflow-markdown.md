# Git 项目上传与 Markdown 基础

## 一、为远程仓库设置别名

### 获取仓库地址

设置远程仓库时使用的是 **SSH 地址**

### 添加远程仓库别名

在本地仓库目录中打开 Git Bash Here，执行

```bash
git remote add origin "仓库SSH地址"
```

### 删除错误的别名

```bash
git remote remove origin
```

然后重新执行

## 二、Git 项目上传的整体流程

### 两个仓库

**本地仓库**：执行 git init后，由本地目录中的 .git保存版本信息

**云端仓库**：在GitHub网站中创建的仓库

本地通常保存正在继续开发的新内容，云端则保存已经发布或此前上传的版本

上传就是把本地的新版本同步到云端，可能发生合并或替换

### 四个位置

```text
资源文件或项目目录
        │
        │ git add 添加到缓冲区
        ▼
Git 缓冲区
        │
        │ git commit 提交到本地仓库
        ▼
Git 本地仓库中的分支
        │
        │ git push origin master 将本地仓库数据push推到云端
        ▼
GitHub 云端仓库中的分支
```

资源可以是单个文件，也可以是整个文件夹；对应命令的使用方式相同。

### 分支同名与不同名

本地上传分支与云端已有分支同名时，数据进行合并

分支名不同时，云端会建立相应的新分支来保存上传内容

## 三、操作 Git 缓冲区

### 添加资源

```bash
git add file
```

将指定文件或文件夹添加到 Git 缓冲区

### 删除资源

```bash
git rm file
```

从 Git 缓冲区删除指定资源，同时删除磁盘中的对应文件

### 还原资源

```bash
git restore file
```

如果本地文件被修改或删除，而 Git 缓冲区中仍有对应内容，可以把文件还原到磁盘中

### 查看状态

```bash
git status
```

查看当前工作目录和 Git 缓冲区的状态，判断文件是否已经被添加、是否有待提交的修改

## 四、提交到本地仓库

### 提交说明

```bash
git commit -m "提交说明"
```

将 Git 缓冲区中的数据提交到本地仓库，并附加一条说明信息

提交说明用于记录本次版本发生了什么变化

## 五、将本地仓库推送到 GitHub

```bash
git push origin master
```

将本地仓库分支的数据推送到origin所指向的云端仓库

## 六、下载开源项目

### 网页打包下载

进入目标仓库，单击绿色的Code按钮，再选择 Download ZIP，GitHub 会把项目资源打成 ZIP 包下载

这种方式受浏览器和网络状况影响

### 使用 git clone

使用的是 Code面板中的 HTTPS 地址

```bash
git clone "仓库HTTPS地址"
```

把目标项目下载到当前目录，并创建一个以项目名命名的文件夹

## 七、Markdown

### 作用

文本修饰语言

需要掌握的内容包括

1. 标题修饰符与多级标题
2. 正文及换行符
3. 文本修饰符
4. 无序列表和有序列表
5. 引用修饰符
6. 超链接与图片
7. 表格
8. 代码块

### 标题修饰符

使用#修饰标题，#的数量决定标题级别

```markdown
# 一级标题
## 二级标题
```

### 正文与换行

正文内容可以直接输入。如果需要明确换行，课堂使用 HTML 的 `<br>` 标签

```markdown
第一行内容<br>
第二行内容
```

### 文本修饰

#### 斜体、粗体与粗斜体

使用星号成对包裹文本：一对表示斜体，两对表示粗体，三对表示粗斜体

```markdown
*斜体样式*
**粗体样式**
***粗斜体样式***
```

#### 删除线

使用两对波浪线包裹文本

```markdown
~~一段测试文本~~
```

#### 行内凸显

使用一对反引号包裹文本

```markdown
`关键词`
```

#### 分割线

使用 5 个星号分隔上下两部分内容

```markdown
*****
```

### 列表

#### 无序列表

使用 *、空格和正文形成一个无序列表项

```markdown
* 物理学
    * 粒子物理
    * 原子核物理
* 计算机科学
    * socket编程
        * accept
        * bind
        * listen
        * connect
```

子级列表通过缩进形成，可以包含多级

#### 有序列表

使用“数字、英文句点、空格、正文”形成有序列表

```markdown
1. 计算机科学
    1. socket编程
        1. accept
        2. connect
```

有序列表和无序列表可以混合使用，但列表标记后必须有空格

### 引用

使用 >、空格和正文形成引用。>越多，引用级别越深。

```markdown
> 一级引用
>> 二级引用
>>> 三级引用
>>>> 四级引用
```

### 超链接与图片

#### 超链接

基本格式：

```markdown
[链接标题](链接地址 "悬停标题")
```

课堂示例的结构：

```markdown
[点击访问百度](https://www.baidu.com "悬停标题")
```

#### 图片

图片语法比超链接多一个！

```markdown
![图片标题](图片地址 "悬停标题")
```

图片地址可以是

- 本地图片的磁盘地址或相对路径
- 网络图片的 URL 地址

### 表格

表格使用竖线 `|` 分隔列。第二行用于分隔表头，并可通过冒号控制对齐方式

```markdown
| 英雄 | 技能 | 排行 |
| :--- | :---: | ---: |
| 关羽 | 偃月刀 | 4 |
| 诸葛亮 | 谋划 | 5 |
```

对齐规则：

- `:---`：左对齐
- `:---:`：居中
- `---:`：右对齐

### 插入代码块

使用三个反引号包围代码。开头的三个反引号后面写语言名，编辑器可按相应语言进行高亮

````markdown
```c
#include <stdio.h>

int main()
{
    return 0;
}
```
````

语言名写在开头三个反引号之后，结尾再使用三个反引号关闭代码块
